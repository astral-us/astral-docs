# Welcome to Astral

Astral makes drones that finish the mission when the network doesn't. We run vision-language models on-device so flights complete with no GPS, no comms, and no operator in the loop.

## What is Astral?

Astral provides:

- **Hardware**: NDAA-compliant autonomous drones (M1-A quadcopter, M1-G rover)
- **On-device autonomy**: Qwen3-VL + ArduPilot + Nav2 running on Jetson Orin
- **SDK**: Open Python SDK for mission planning and integration
- **Platform**: Cloud infrastructure for fleet management and telemetry

## Why Astral?

### Mission completion in denied environments

Vision-language models run on the drone's Jetson Orin, not in the cloud. When GPS drops, comms jam, or the operator is out of range, the drone keeps going.

### Open Python SDK

Plan missions, integrate with your stack, and build custom autonomy in Python. The SDK is open source on [GitHub](https://github.com/astral-us); the cloud platform and on-device intelligence stack are commercial.

### NDAA-compliant by design

Cube Orange flight controller, Jetson Orin compute, NDAA-compliant sensors. Built for defense, public safety, and infrastructure customers who can't fly DJI.
